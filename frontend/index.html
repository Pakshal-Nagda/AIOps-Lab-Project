Project Medhā - AIOps Production Architecture

End-to-end ML lifecycle design compliant with course evaluation guidelines.

1. Audio Ingestion & VAD

Microphone stream captured at 16kHz PCM. Streaming VAD identifies active speech intervals, intra-line pauses, and hesitation gaps (>1.5s).

2. Feature Extraction

ONNX Preprocessor model converts 16kHz audio array into 80-channel log-mel spectrogram features in real time with zero PyTorch runtime dependencies.

3. Quantized ASR Inference

Quantized INT8 Conformer-CTC acoustic model runs on ONNX Runtime CPU provider. Predicts 257-token Sanskrit CTC posteriors decoded into Devanagari text in <150ms.

4. Space-Agnostic Aligner

Strictly ignores spaces and punctuation in phonetic matching while preserving original formatting. Injects inline hesitation badges directly into continuous flow.
